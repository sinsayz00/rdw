# 연구 주제 발표 (쉬운 버전) — 웹 발표용

웹 에이전시 실무와 생성형 AI에 관한 연구주제 발표 자료(12장)를 브라우저에서 넘겨 볼 수 있게 만든 정적 웹 페이지입니다.

## 폴더 구성

```
index.html            슬라이드 12장 전체
css/deck.css          화면 맞춤, 조작 막대, 노트, 눈 깜빡임
js/deck.js            슬라이드 넘기기
assets/fonts/         아리따 돋움(보통·굵게)
assets/img/           12쪽 캐릭터 그림
.nojekyll             GitHub Pages가 파일을 그대로 쓰게 하는 빈 파일
```

## 보는 법

- 내 컴퓨터: `index.html`을 브라우저로 엽니다.
- GitHub Pages: 저장소에 올린 뒤 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하면 주소가 생깁니다.

## 조작

| 동작 | 키 |
|---|---|
| 다음 / 이전 | → ← · Space · PageDown / PageUp |
| 처음 / 끝 | Home / End |
| 발표자 노트 | N |
| 전체 화면 | F |
| 휴대폰·태블릿 | 좌우로 밀기 |

화면 아래에 마우스를 올리면 조작 막대가 나타납니다. 주소 끝 `#3`처럼 쪽 번호를 붙이면 그 쪽으로 바로 열립니다.

## 알아 둘 점

- 아리따 돋움은 아모레퍼시픽의 무료 글꼴입니다. 공개 저장소에 글꼴 파일을 올리기 전에 배포 조건을 확인하세요.
- 12쪽 캐릭터 그림은 발표자 본인의 캐릭터입니다.
